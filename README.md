# Saryarqa City Simulator

Проект команды для HackAlem AI.

## Идея

Интерактивный симулятор помогает сравнивать планы развития районов города. Пользователь выбирает мероприятия, а система проверяет ограничения, рассчитывает изменения показателей и показывает компромиссы между сценариями.

## Статус

Начальная структура проекта. Разработка симулятора и интерфейса продолжается.

## Источники данных

Для карты Астаны мы используем упрощённую геобазу, собранную из открытых источников.

Основной источник геоданных — OpenStreetMap (OSM). Из него используются только необходимые для симулятора объекты:

- основные магистрали;
- крупные перекрёстки;
- парки и зелёные зоны;
- ключевые городские объекты;
- транспортные узлы;
- крупные общественные здания.

Полная база 2GIS не загружается: тысячи магазинов, кафе и других второстепенных POI для работы симулятора не требуются.

2GIS MapGL может использоваться как визуальная картографическая подложка, а данные для анализа ИИ хранятся отдельно в нашей упрощённой базе.

ИИ не придумывает координаты самостоятельно. Он работает с существующими объектами и их ID, после чего backend связывает выбранный объект с реальной геометрией карты.
