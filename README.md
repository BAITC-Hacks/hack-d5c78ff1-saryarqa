# Saryarqa City Simulator

Проект команды для HackAlem AI.

## Идея

Интерактивный симулятор помогает сравнивать планы развития районов города. Пользователь выбирает мероприятия, а система проверяет ограничения, рассчитывает изменения показателей и показывает компромиссы между сценариями.

## Статус

Начальная структура проекта. Разработка симулятора и интерфейса продолжается.
